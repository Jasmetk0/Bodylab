# FORMA · Soukromí a bezpečnost

FORMA zpracovává tělesná měření a záznamy o stravě. Repozitář není úložiště osobních dat.

- Nikdy necommituj reálné váhy, InBody reporty, fotografie, výpisy WHOOP, zdravotní poznámky ani zálohy JSON/CSV.
- Nedávej soukromá data do GitHub Issues, PR popisů, logů, testovacích fixture ani screenshotů.
- Zálohy importuj v aplikaci přes **Data a zálohy** a ukládej mimo GitHub.
- `localStorage` není šifrované. Na sdíleném zařízení může být nevhodné.
- GitHub Pages a veřejné repozitáře zveřejňují zdrojový kód a mohou zveřejnit i stránku.
- Cloudovou synchronizaci nezavádět bez autentizace, přístupových pravidel, bezpečného ukládání a možnosti smazání účtu.
- Pouhé smazání citlivého souboru z posledního commitu nezaručuje jeho odstranění z historie Gitu.

Pokud objevíš chybu související se soukromím, neopisuj osobní data do veřejného issue.
